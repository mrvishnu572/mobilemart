# MobileMart Sales Reports Update

## Added
- Admin analytics date selector: last 7 days, 30 days, 90 days, 12 months, all time, and custom dates.
- Excel-compatible CSV export containing business KPIs, monthly sales, top-selling phones, payment methods, and promo performance.
- PDF sales report generated by the backend using the same selected date range.
- Admin-only PDF endpoint: `GET /api/admin/dashboard/report.pdf` (mounted under the existing admin API prefix).

## Notes
- The CSV opens directly in Microsoft Excel and other spreadsheet applications.
- PDF generation uses the existing `pdfkit` backend dependency.
- The report is based on the same dashboard analytics service and date filters.
- Environment files are excluded from this ZIP. Keep your existing `.env` files.

## Validation
- `node --check` passed for the admin controller, routes, and analytics service.
- TypeScript JSX transpile check passed for `AdminDashboardPage.jsx`.
- A full Vite production build and live MongoDB/PDF download test were not run in this environment.
